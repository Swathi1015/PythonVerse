List Comprehension

List comprehension provides a short way to create a list from another sequence.

numbers = [1,2,3,4,5]

squares = [x*x for x in numbers]

print(squares)

Output: [1, 4, 9, 16, 25]

📦

*args

*args allows a function to accept any number of positional arguments.

def total(*numbers):
    return sum(numbers)

print(total(10,20,30,40))

Output: 100

🔑

**kwargs

**kwargs allows a function to accept multiple keyword arguments.

def student(**details):
    print(details)

student(name="Swathi",branch="CSE")
🎨

Decorators

A decorator is a function that modifies or extends the behavior of another function.

def welcome(func):
    def wrapper():
        print("Welcome!")
        func()
    return wrapper

@welcome
def python():
    print("Learn Python")

python()
🔄

Generators

A generator produces values one at a time using the yield keyword.

def numbers():
    yield 1
    yield 2
    yield 3

for n in numbers():
    print(n)

Generators are useful when working with large amounts of data because they produce values one at a time.

🔁

Iterators

numbers = [10,20,30]
iterator = iter(numbers)

print(next(iterator))
print(next(iterator))
print(next(iterator))

iter() creates an iterator and next() retrieves the next value.
