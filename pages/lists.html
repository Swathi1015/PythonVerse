Python Lists

Learn how to store and manage multiple values in a single variable.

💡

What is a List?

A list is an ordered collection of items. Lists can store multiple values and can contain different data types.

fruits = ["Apple","Banana","Mango"]

print(fruits)

Lists are created using [ ] square brackets.

🔢

List Indexing

Like strings, list items have indexes starting from 0.

fruits = ["Apple","Banana","Mango"]

print(fruits[0])
print(fruits[1])
print(fruits[-1])

Output: Apple, Banana, Mango

✏️

Changing List Items

Lists are mutable, which means their values can be changed.

fruits = ["Apple","Banana","Mango"]
fruits[1] = "Orange"

print(fruits)

Output: ["Apple", "Orange", "Mango"]

🛠️

Important List Methods

➕ append()
Add item at the end
📍 insert()
Add item at a position
❌ remove()
Remove an item
🗑️ pop()
Remove by index
🔢 sort()
Sort the list
🔄 reverse()
Reverse the list
📏 len()
Find number of items
🔎 index()
Find item position
💻

Python Example

fruits = ["Apple","Banana"]

fruits.append("Mango")
fruits.insert(1,"Orange")
fruits.remove("Banana")

print(fruits)
