Python File Handling

Learn how to create, read, write and manage files using Python.

💡

What is File Handling?

File handling allows Python programs to store data permanently in files and read that data whenever needed.

file = open("data.txt","r")
content = file.read()
print(content)
file.close()

Python uses the open() function to work with files.

🔑

File Modes

📖 "r"
Read a file
✏️ "w"
Write to a file
➕ "a"
Add content to a file
📄 "x"
Create a new file
📖

Reading a File

file = open("data.txt","r")
content = file.read()
print(content)
file.close()

read() reads the complete content of the file.

✍️

Writing to a File

file = open("data.txt","w")
file.write("Hello Python!")
file.close()

The "w" mode writes data to the file. Be careful: it can replace existing content.

➕

Appending Data

file = open("data.txt","a")
file.write("\\nWelcome to Python")
file.close()

The "a" mode adds new content without removing existing content.

✨

Using with Statement

The with statement automatically closes the file after the operation.

with open("data.txt","r") as file:
    content = file.read()
    print(content)

This is the recommended way to work with files in Python.

💼

Real-Time Example

File handling can be used to store student information, logs, reports and application data.

with open("students.txt","w") as file:
    file.write("Swathi - CSE")
