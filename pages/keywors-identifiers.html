Keywords & Identifiers

Learn the special words and naming rules used in Python.

🔑

What are Keywords?

Keywords are special reserved words in Python. They have a predefined meaning and cannot normally be used as variable or function names.

if
else
for
while
def
class
return
True
False
None
🏷️

What are Identifiers?

Identifiers are the names we give to variables, functions, classes and other objects in Python.

name = "Python"
age = 22

def greet():
    print("Hello")

Here name, age and greet are identifiers.

📌

Identifier Rules

✅ Can contain letters, numbers and underscore.
✅ Cannot start with a number.
✅ Cannot contain spaces.
✅ Cannot use Python keywords.
✅ Python identifiers are case-sensitive.
✅

Valid Identifiers

name = "Python"
student_name = "Swathi"
age2 = 22
_total = 100
❌

Invalid Identifiers

2name = "Python" ❌
student name = "Bangaramm" ❌
class = "CSE" ❌
