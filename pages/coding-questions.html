Beginner Level

1️⃣ Reverse a String

Write a Python program to reverse a given string.

Input: Hello
Output: olleH
💡 Hint:

Think about string slicing or a loop.

2️⃣ Check Palindrome

Check whether a string or number reads the same forward and backward.

Input: madam
Output: Palindrome
💡 Hint:

Compare the original value with its reverse.

3️⃣ Factorial of a Number

Find the factorial of a given number.

Input: 5
Output: 120
💡 Hint:

You can use a loop or recursion.

4️⃣ Fibonacci Series

Print the Fibonacci sequence up to N terms.

Input: 6
Output: 0 1 1 2 3 5
💡 Hint:

Each number is the sum of the previous two numbers.

5️⃣ Prime Number

Check whether a given number is prime.

Input: 7
Output: Prime
💡 Hint:

Check whether the number has any divisor other than 1 and itself.

6️⃣ Even or Odd

Check whether a number is even or odd.

Input: 10
Output: Even
💡 Hint:

Use the modulus operator %.

7️⃣ Largest of Three Numbers

Find the largest number among three numbers.

Input: 10 25 15
Output: 25
