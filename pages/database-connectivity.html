What is Database Connectivity?

Database connectivity means connecting a Python program to a database so that the program can store, read, update and delete data.

🔍 Read

🗑️ Delete

Save changes permanently

SQLite

SQLite is a lightweight relational database. Python provides the built-in sqlite3 module to work with SQLite.

import sqlite3

connection = sqlite3.connect("students.db")

print("Database connected successfully!")

The connect() function creates a connection to the database. If the database does not exist, SQLite can create it.

🔌

Creating a Connection

import sqlite3

connection = sqlite3.connect("college.db")

print("Connected!")
💡 Remember:

The connection object represents the connection between your Python program and the database.

🎯

Cursor Object

A cursor is used to execute SQL commands from Python.

import sqlite3

connection = sqlite3.connect("college.db")
cursor = connection.cursor()

Think of the cursor as the object through which Python sends SQL commands to the database.

🏗️

Create a Table

import sqlite3

connection = sqlite3.connect("college.db")
cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS students (
    id INTEGER PRIMARY KEY,
    name TEXT,
    branch TEXT,
    marks INTEGER
)
""")

connection.commit()
connection.close()

CREATE TABLE creates the structure where student data will be stored.

➕

Insert Data

cursor.execute(
    "INSERT INTO students (name,branch,marks) VALUES (?,?,?)",
    ("Swathi","CSE",85)
)

connection.commit()
💡 Important:

The ? placeholders are used for parameterized queries. This is safer than directly building SQL strings with user input.

🔍

Read Data — SELECT

cursor.execute("SELECT * FROM students")

students = cursor.fetchall()

for student in students:
    print(student)

fetchall() retrieves all available rows from the result.

1️⃣

fetchone()

When you need only one row, you can use fetchone().

cursor.execute("SELECT * FROM students")

student = cursor.fetchone()
print(student)
✏️

Update Data

cursor.execute(
    "UPDATE students SET marks=? WHERE name=?",
    (90,"Swathi")
)

connection.commit()

This changes Swathi's marks from the previous value to 90.

🗑️

Delete Data

cursor.execute(
    "DELETE FROM students WHERE name=?",
    ("Swathi",)
)

connection.commit()
💾

commit() & close()

commit() saves database changes.

close() closes the database connection when the work is finished.

connection.commit()
connection.close()

Complete CRUD Example

CRUD stands for:

➕ Create
INSERT
🔍 Read
SELECT
✏️ Update
UPDATE
🗑️ Delete
DELETE
import sqlite3

connection = sqlite3.connect("college.db")
cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT,
    branch TEXT,
    marks INTEGER
)
""")

cursor.execute(
    "INSERT INTO students (name,branch,marks) VALUES (?,?,?)",
    ("Rahul","CSE",88)
)

connection.commit()

cursor.execute("SELECT * FROM students")
rows = cursor.fetchall()

for row in rows:
    print(row)

connection.close()
