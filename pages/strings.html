Python Strings

Learn how to store, access and manipulate text in Python.

💡

What is a String?

A string is a sequence of characters enclosed inside single quotes, double quotes or triple quotes.

name = "Swathi"
language = 'Python'
message = """Hello Python!"""

Strings can contain letters, numbers, spaces and special characters.

🔢

String Indexing

Each character in a string has an index. Python starts indexing from 0.

word = "Python"

print(word[0])
print(word[1])
print(word[-1])

Output: P   y   n

✂️

String Slicing

Slicing is used to extract a part of a string.

word = "Python"

print(word[0:3])
print(word[2:6])

Output: Pyt and thon

🛠️

Useful String Methods

🔠 upper()
Converts to uppercase
🔡 lower()
Converts to lowercase
✨ capitalize()
Capitalizes first letter
🔎 find()
Finds a character/text
🔄 replace()
Replaces text
📏 len()
Finds string length
💻

Python Example

name = "python programming"

print(name.upper())
print(name.lower())
print(name.capitalize())
