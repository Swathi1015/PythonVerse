Object-Oriented Programming

Learn how Python uses Classes and Objects to build organized programs.

💡

What is OOP?

Object-Oriented Programming is a programming approach where we organize code using objects and classes.

🏗️ Class → Blueprint
🏠 Object → Real thing created from the blueprint

For example, Car can be a class and a particular car can be an object.

🏗️

Class & Object

class Student:
    pass

student1 = Student()
print(student1)

Student is the class and student1 is an object.

⚙️

__init__() Method

The __init__() method runs automatically when an object is created. It is commonly used to initialize object data.

class Student:
    def __init__(self,name,age):
        self.name = name
        self.age = age

student1 = Student("Swathi",22)

print(student1.name)
print(student1.age)
🔧

Methods

A method is a function defined inside a class.

class Student:
    def greet(self):
        print("Hello Python!")

student1 = Student()
student1.greet()
🧬

Inheritance

Inheritance allows one class to reuse properties and methods from another class.

class Animal:
    def sound(self):
        print("Animal makes a sound")

class Dog(Animal):
    pass

dog = Dog()
dog.sound()

Dog inherits the sound() method from Animal.

🎯

Four Main OOP Concepts

🔒 Encapsulation
Protect and organize data
🧬 Inheritance
Reuse existing code
🎭 Polymorphism
Same interface, different behavior
🎨 Abstraction
Hide unnecessary details

Real-Time Example

OOP is commonly used in applications such as banking systems, games, e-commerce applications and student management systems.

class BankAccount:
    def __init__(self,balance):
        self.balance = balance

    def show_balance(self):
        print("Balance:",self.balance)

account = BankAccount(5000)
account.show_balance()
