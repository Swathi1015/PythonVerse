Modules & Packages

Learn how to organize, reuse and manage Python code.

💡

What is a Module?

A module is simply a Python file containing functions, variables or classes that can be reused in another Python program.

# math_tools.py

def add(a,b):
    return a + b

The file math_tools.py is a module.

📥

Importing a Module

Use import to use a module in another Python program.

import math

print(math.sqrt(25))
print(math.pi)

Output: 5.0 and the value of π.

🎯

Import Specific Functions

from math import sqrt

print(sqrt(36))

Here we import only the sqrt() function instead of the complete module.

📦

What is a Package?

A package is a collection of related Python modules organized inside a folder.

myproject/
  📂 calculations/
    📄 add.py
    📄 multiply.py
    📄 divide.py

Packages help us organize large Python projects into smaller parts.
