Python Data Types

Learn how Python understands and stores different kinds of data.

💡

What are Data Types?

A data type tells Python what kind of value we are working with. For example, a number, text, or a collection of values.

🔢intWhole numbers
Example: 25
🔣floatDecimal numbers
Example: 3.14
📝strText
Example: "Python"
✅boolTrue or False
🧠

Common Python Data Types

🔢 Integer — 10
🔣 Float — 10.5
📝 String — "Hello"
✅ Boolean — True
📚 List — [1,2,3]
📦 Tuple — (1,2,3)
🧩 Set — {1,2,3}
📖 Dictionary — {"name":"Sam"}
