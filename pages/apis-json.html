APIs & JSON

Learn how Python applications communicate with other applications and exchange data using APIs and JSON.

💡

What is an API?

API stands for Application Programming Interface.

An API allows two different software applications to communicate with each other and exchange data.

🌍 Simple Example:

A weather application needs weather information. Instead of storing all weather data itself, it can request the data from a weather API.

📱 App
🌐 API
🗄️ Server
📊 Data
🔄

How an API Works

1️⃣ Python application sends a request

2️⃣ API receives the request

3️⃣ Server processes the request

4️⃣ Server sends a response

5️⃣ Python reads the response

Request → API → Server → Response

📦

What is JSON?

JSON stands for JavaScript Object Notation.

JSON is a lightweight format commonly used for exchanging data between applications.

{
  "name":"Swathi",
  "age":22,
  "branch":"CSE"
}

JSON looks similar to a Python dictionary, which makes it very convenient to work with in Python.

🆚

Python Dictionary vs JSON

🐍 Python Dictionary

Python object

Uses dict syntax

Used inside Python

🌐 JSON

Data exchange format

Used between applications

Language independent

🔧

JSON Module in Python

Python provides the built-in json module to work with JSON data.

import json

The two important operations are:

🔄 json.dumps()
Python → JSON
🔄 json.loads()
JSON → Python
📤

json.dumps()

dumps() converts a Python object into a JSON string.

import json

student = {
  "name":"Swathi",
  "marks":90
}

data = json.dumps(student)
print(data)
Remember:

dumps = Python object → JSON string

📥

json.loads()

loads() converts a JSON string into a Python object.

import json

data = '{"name":"Swathi","marks":90}'

student = json.loads(data)
print(student["name"])

Output: Swathi

🌐

Calling an API with Python

Python can use the requests library to send HTTP requests to APIs.

import requests

response = requests.get("https://example.com/api")

print(response.status_code)
print(response.json())
💡 Important:

requests.get() sends a GET request. response.json() converts a JSON response into a Python object.

    data = response.json()

else:
