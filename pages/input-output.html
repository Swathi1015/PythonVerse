Input & Output

Learn how Python communicates with the user.

💡

What is Input?

Input means taking information from the user. Python provides the input() function to receive information from the keyboard.

name = input("Enter your name: ")
print(name)
⌨️ User
⬇️
🐍 Python Program
🖥️

What is Output?

Output means displaying information on the screen. Python uses the print() function to display output.

print("Hello, Python!")
print(10 + 20)
Output will appear here...
🔄

Input + Output Together

name = input("Enter your name: ")
print("Hello", name)

The user enters a value → Python stores it → print() displays the result.

⚠️

Important Point

💡 input() normally returns the user's value as a string.
🔢 Use int() when you need an integer.
🔣 Use float() when you need a decimal number.
age = int(input("Enter your age: "))
height = float(input("Enter your height: "))
