Decision Making

Learn how Python makes decisions using conditions.

💡

What is Decision Making?

Decision making allows a program to choose what to do based on a condition.

➡️

1️⃣

if Statement

The if statement executes code only when the condition is True.

age = 20

if age >= 18:
    print("You are eligible")
2️⃣

if-else Statement

Use else when you want another action if the condition is False.

age = 16

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")
3️⃣

if-elif-else

Use elif when you have multiple conditions.

marks = 75

if marks >= 90:
    print("Grade A+")
elif marks >= 70:
    print("Grade A")
elif marks >= 50:
    print("Grade B")
else:
    print("Need Improvement")
4️⃣

Nested if

An if statement inside another if statement is called nested if.

age = 20
citizen = True

if age >= 18:
    if citizen:
        print("You can vote")

Real-Time Example

Imagine an online shopping website checking whether a customer gets free delivery.

cart = 1200

if cart >= 1000:
    print("Free Delivery 🚚")
else:
    print("Delivery Charges Apply")
