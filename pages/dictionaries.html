Python Dictionaries

Learn how to store and access data using key-value pairs.

💡

What is a Dictionary?

A dictionary stores data in key-value pairs. Each key is used to access its corresponding value.

student = {
    "name": "Swathi",
    "age": 22,
    "branch": "CSE"
}

print(student)

Dictionaries are created using { } curly brackets.

🔑

Accessing Values

Use the key to access its value.

student = {
    "name": "Swathi",
    "age": 22
}

print(student["name"])
print(student["age"])

Output: Swathi and 22

✏️

Changing Values

Dictionaries are mutable, so their values can be changed.

student = {"name":"Swathi","age":22}

student["age"] = 23

print(student)
➕

Adding Items

Add a new key-value pair by assigning a value to a new key.

student = {"name":"Swathi"}

student["branch"] = "CSE"

print(student)
🗑️

Removing Items

student = {
    "name":"Swathi",
    "age":22,
    "branch":"CSE"
}

student.pop("age")
print(student)
🛠️

Important Dictionary Methods

🔑 keys()
Returns all keys
💎 values()
Returns all values
🔗 items()
Returns key-value pairs
➕ update()
Updates dictionary
🗑️ pop()
Removes an item
🔎 get()
Gets a value safely
