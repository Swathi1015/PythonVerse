What is a Variable?

A variable is a name used to store a value in a Python program. Think of it like a labelled box where you can keep information and use it later.

Important Rules

✅ Variable names can contain letters, numbers and underscore.
✅ A variable name cannot start with a number.
✅ Python is case-sensitive.
✅ Use meaningful names whenever possible.
