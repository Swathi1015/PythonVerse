2. Comparison Operators

Equal ==10 == 10 → True
Not Equal !=10 != 5 → True
Greater >10 > 5 → True
Less <5 < 10 → True
Greater/Equal >=10 >= 10 → True
Less/Equal <=5 <= 10 → True

3. Logical Operators

AND andBoth conditions True
OR orAny one condition True
NOT notReverses the result
