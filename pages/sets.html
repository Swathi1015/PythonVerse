Python Sets

Learn how to store unique values and perform set operations.

💡

What is a Set?

A set is an unordered collection of unique elements. A set automatically removes duplicate values.

numbers = {10,20,30,20,10}

print(numbers)

Output will contain only unique values.

⭐

Important Properties

🚫 No Duplicates
Duplicate values are removed
🔀 Unordered
No fixed index positions
✏️ Mutable
Elements can be added or removed
⚡ Fast Membership
Useful for checking values
➕

Adding Elements

Use add() to add an element to a set.

fruits = {"Apple","Banana"}

fruits.add("Mango")
print(fruits)
🗑️

Removing Elements

You can use remove() or discard().

fruits = {"Apple","Banana","Mango"}

fruits.remove("Banana")
print(fruits)
🔗

Set Operations

A = {1,2,3}
B = {3,4,5}

print(A | B) # Union
print(A & B) # Intersection
print(A - B) # Difference

Union combines sets. Intersection finds common values. Difference finds values present only in the first set.

💻

Real-Time Example

Suppose two classes have students and we want to find common students.

class_a = {"Asha","Ravi","Kiran"}
class_b = {"Ravi","Kiran","Priya"}

common = class_a & class_b
print(common)
