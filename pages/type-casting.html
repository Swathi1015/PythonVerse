Type Casting

Learn how to convert one data type into another in Python.

💡

What is Type Casting?

Type casting means converting a value from one data type to another. Python provides functions like int(), float(), str() and bool() for conversion.

📝String"25"
➡️
🔢Integer25
🔢

Common Type Casting Functions

🔢int()Convert to integer
🔣float()Convert to decimal
📝str()Convert to string
✅bool()Convert to Boolean
💻

Example

age = "22"
age = int(age)

print(age)
print(type(age))
