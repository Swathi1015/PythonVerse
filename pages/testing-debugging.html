Testing & Debugging

Learn how to find errors, test your Python programs and fix bugs confidently.

💡

What is Testing?

Testing means checking whether a program works correctly for different inputs and produces the expected output.

Example:

If a function should add two numbers, we test it with different values to make sure it gives the correct result.

def add(a,b):
    return a+b

print(add(5,3))

Expected output: 8

🐛

What is Debugging?

Debugging is the process of finding and fixing errors or bugs in a program.

Write Code → Run Program → Error/Unexpected Output → Find Bug → Fix Bug → Test Again
💡 Simple Meaning:

Testing finds that something is wrong. Debugging helps us find out why it is wrong and fix it.

⚠️

Types of Errors in Python

✍️ Syntax Error
🏃 Runtime Error
🧠 Logical Error

Syntax Error: Python syntax is written incorrectly.

if age >= 18
    print("Eligible")

The colon : is missing.

Runtime Error: The program starts running but an error occurs during execution.

number = 10
print(number / 0)

This causes ZeroDivisionError.

Logical Error: Program runs without crashing, but gives the wrong result.

a = 10
b = 5
print(a-b)

If the programmer intended addition, the code runs but gives the wrong answer.

🔍

Reading Error Messages

Python error messages usually provide useful information about where and why an error occurred.

Traceback (most recent call last):
  File "program.py", line 2
    print(10 / 0)
ZeroDivisionError: division by zero
🔹 File name tells where the error occurred.

🔹 Line number tells which line caused the problem.

🔹 Error type tells what kind of error occurred.

🔹 Error message gives additional information.
🛠️

🧯

Exception Handling

Python provides try and except to handle runtime errors without crashing the entire program.

try:
    number = int(input("Enter number: "))
    print(10 / number)
except ZeroDivisionError:
    print("Cannot divide by zero")
💡 Remember:

try contains risky code. except handles the error.

🔄

try, except, else & finally

try:
    number = int(input("Enter number: "))
except ValueError:
    print("Invalid input")
else:
    print("Valid input")
finally:
    print("Program finished")
🧪 try
Test risky code
🚨 except
Handle error
✅ else
Runs if no error
🔚 finally
Runs at the end
📝

Assertions

An assertion is used to check whether a condition is true while developing or testing a program.

age = 20
assert age >= 18
print("Eligible")

If the condition is false, Python raises an AssertionError.

🧪

Unit Testing

Unit testing means testing small individual parts of a program, such as functions.

import unittest

def add(a,b):
    return a+b

class TestAdd(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(2,3),5)

unittest.main()
💡 Interview Tip:

Know the basic idea of unit testing and the purpose of unittest. You don't need to memorize every method.

4️⃣ Check input values

7️⃣ Check assumptions
8️⃣ Test edge cases
🔎

Debugging with print()

def calculate(a,b):
    print("a =",a)
    print("b =",b)
    return a+b

print(calculate(10,20))

Printing intermediate values helps us understand what is happening inside the program.

🧠

Edge Case Testing

Edge cases are unusual or boundary inputs that can reveal bugs.

For a program that calculates division, test:

✅ Normal number
⚠️ Zero
⚠️ Negative number
⚠️ Very large number
⚠️ Invalid input
