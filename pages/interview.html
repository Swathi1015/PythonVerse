1. What is Python?

💡 Interview Answer:

Python is a high-level, interpreted, general-purpose programming language known for its simple and readable syntax. It is widely used in web development, automation, data science, artificial intelligence and machine learning.

print("Hello Python")

4. List vs Tuple?

📋 List

Mutable

Uses [ ]

Can be modified

📦 Tuple

Immutable

Uses ( )

Cannot be modified

🎯 Interview Answer:

A list is mutable, whereas a tuple is immutable. Therefore, list elements can be changed after creation, while tuple elements cannot be changed.

🔐

6. Difference between == and is?

==

Checks whether two objects have equal values.


is

Checks whether two variables refer to the same object.

a = [1,2,3]
b = [1,2,3]

print(a == b)
print(a is b)
🔄

7. What is a function?

A function is a reusable block of code designed to perform a specific task.

def add(a,b):
    return a+b

print(add(10,20))
🔁

8. What is recursion?

Recursion is a technique where a function calls itself until a base condition is reached.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n-1)
📦

9. What are *args and **kwargs?

*args

Allows a function to accept multiple positional arguments.

**kwargs

Allows a function to accept multiple keyword arguments.

def demo(*args, **kwargs):
    print(args)
    print(kwargs)
⚡

10. What is a Lambda function?

A lambda function is a small anonymous function written using the lambda keyword.

square = lambda x: x*x

print(square(5))

Output: 25

🏛️

11. What is OOP?

Object-Oriented Programming organizes programs using classes and objects.

🔒 Encapsulation
🧬 Inheritance
🔄 Polymorphism
🎭 Abstraction
🏗️

12. What is a class and object?

A class is a blueprint for creating objects. An object is an instance of a class.

class Student:
    pass

student1 = Student()
🧬

13. What is inheritance?

Inheritance allows one class to acquire properties and methods of another class.

class Parent:
    def show(self):
        print("Parent")

class Child(Parent):
    pass
🔄

14. What is polymorphism?

Polymorphism means the same interface or method name can behave differently depending on the object or context.

🧯

15. What is exception handling?

Exception handling allows a program to handle runtime errors without unexpectedly terminating.

try:
    number = int(input())
    print(10 / number)

except ZeroDivisionError:
    print("Cannot divide by zero")
🚀

16. What is a generator?

A generator produces values one at a time using the yield keyword.

def numbers():
    yield 1
    yield 2
    yield 3
🔧

17. What is an iterator?

An iterator is an object that allows us to access elements one at a time. Python uses iter() and next() to work with iterators.

numbers = [10,20,30]

it = iter(numbers)

print(next(it))
print(next(it))
✨

18. What is a decorator?

A decorator is a function that modifies or extends the behavior of another function without changing its original code.

def decorator(func):
    def wrapper():
        print("Before function")
        func()
    return wrapper
📁

19. What is file handling?

File handling allows Python programs to create, read, write and modify files.

file = open("data.txt","r")
data = file.read()
print(data)
file.close()
🗄️

20. What is database connectivity?

Database connectivity allows Python applications to communicate with databases to store, retrieve, update and delete data.

➕ INSERT
🔍 SELECT
✏️ UPDATE
🗑️ DELETE
🌐

21. What is an API?

An API allows different software applications to communicate and exchange data.

Application → Request → API → Server → Response → Application
📦

22. What is JSON?

JSON is a lightweight data format commonly used for exchanging data between applications.

{
  "name":"Swathi",
  "age":22
}
⏱️

23. What is time complexity?

Time complexity describes how the running time of an algorithm grows as the input size increases.

🟢 O(1)
Constant
🔵 O(n)
Linear
🟡 O(n²)
Quadratic
🔴 O(log n)
Logarithmic
🧪

24. What is unit testing?

Unit testing tests small individual parts of a program, usually functions, to verify that they behave correctly.

🐛

25. What is debugging?

Debugging is the process of identifying and fixing errors or bugs in a program.

Write Code → Run → Find Error → Understand Error → Fix → Test Again
⚡
