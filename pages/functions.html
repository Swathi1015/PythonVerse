Python Functions

Learn how to create reusable and organized blocks of code.

💡

What is a Function?

A function is a reusable block of code designed to perform a specific task.

def greet():
    print("Hello Python!")

greet()

Here def is used to define a function and greet() calls the function.

1️⃣

Parameters & Arguments

Parameters receive values inside a function. The values passed while calling the function are called arguments.

def greet(name):
    print("Hello", name)

greet("Swathi")

name → parameter | "Swathi" → argument

↩️

Return Statement

The return statement sends a result back from a function.

def add(a,b):
    return a + b

result = add(10,20)
print(result)

Output: 30

🌍

Local & Global Scope

A local variable exists inside a function. A global variable is declared outside a function.

x = 10

def show():
    y = 20
    print(y)

show()
print(x)
🔄

Recursion

When a function calls itself, it is called recursion.

def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)

countdown(5)
⚡

Lambda Function

A lambda is a small anonymous function written in a single expression.

square = lambda x: x * x

print(square(5))

Output: 25

💼

Real-Time Example

Functions are useful when the same task needs to be performed many times, such as calculating a shopping bill.

def calculate_total(price,quantity):
    return price * quantity

total = calculate_total(500,3)
print("Total:",total)
