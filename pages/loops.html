What is a Loop?

A loop allows us to execute the same block of code multiple times without writing the same code again and again.

for Loop

A for loop is used to repeat code for each item in a sequence.

for i in range(5):
    print(i)

Output: 0 1 2 3 4

2️⃣

while Loop

A while loop repeats as long as its condition is True.

i = 1

while i <= 5:
    print(i)
    i += 1

Output: 1 2 3 4 5

🔢

range()

The range() function generates a sequence of numbers, commonly used with for loops.

range(5) → 0, 1, 2, 3, 4
range(1, 6) → 1, 2, 3, 4, 5
🛑

break

break immediately stops the loop.

for i in range(10):
    if i == 5:
        break
    print(i)
⏭️

continue

continue skips the current iteration and moves to the next one.

for i in range(5):
    if i == 2:
        continue
    print(i)
💻

Real-Time Example

Suppose an online shopping application wants to display all products in a cart.

products = ["Laptop","Phone","Mouse"]

for product in products:
    print(product)
