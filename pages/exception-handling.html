Exception Handling

Learn how to handle errors and keep your Python programs running safely.

💡

What is an Exception?

An exception is an error that occurs while a Python program is running. If it is not handled, the program may stop unexpectedly.

number = 10
print(number / 0)

This causes a ZeroDivisionError because a number cannot be divided by zero.

🛡️

try & except

Use try for code that may cause an error and except to handle that error.

try:
    number = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero!")

Instead of crashing, the program handles the error gracefully.

🔄

try, except & else

try:
    number = 10 / 2
except ZeroDivisionError:
    print("Invalid division")
else:
    print("Result:",number)

else runs when no exception occurs.

🧹

finally

The finally block runs whether an exception occurs or not.

try:
    print("Processing...")
except:
    print("Something went wrong")
finally:
    print("Operation completed")
🎯

Handling Multiple Errors

try:
    number = int(input("Enter number: "))
    result = 100 / number
    print(result)
except ValueError:
    print("Please enter a number")
except ZeroDivisionError:
    print("Number cannot be zero")
💼

Real-Time Example

Exception handling is useful when taking input from users, processing files, connecting to databases and working with APIs.
