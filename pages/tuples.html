Python Tuples

Learn how to store multiple values that should not be changed.

💡

What is a Tuple?

A tuple is an ordered collection of items. Unlike lists, tuples are immutable, which means their values cannot be changed after creation.

colors = ("Red","Blue","Green")

print(colors)

Tuples are usually created using ( ) parentheses.

🔢

Tuple Indexing

Tuple elements also have indexes starting from 0.

colors = ("Red","Blue","Green")

print(colors[0])
print(colors[1])
print(colors[-1])

Output: Red, Blue, Green

🔒

Tuple is Immutable

Once a tuple is created, you cannot directly change, add or remove its elements.

numbers = (10,20,30)

numbers[0] = 100

# TypeError ❌

If you need to modify data frequently, use a list instead.

🛠️

Important Tuple Methods

🔎 count()
Counts an item
📍 index()
Finds item position
📏 len()
Finds number of items
⚖️

List vs Tuple

List → [10,20,30] → Mutable ✏️
Tuple → (10,20,30) → Immutable 🔒

Use a list when data needs to change. Use a tuple when data should remain fixed.
